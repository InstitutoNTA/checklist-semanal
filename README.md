# Checklist Semanal

Planilha de acompanhamento das atividades semanais de mentorias, aulas de inglês, edição de vídeos e projetos (EmpregaDados, TFTEC, Curseduca).

## Arquivos

| Arquivo | O que é |
|---|---|
| `Checklist_Semanal.xlsx` | Checklist pronto para uso, com links, status e progresso |
| `checklist_atividades.csv` | Lista original de atividades por dia |
| `central_de_links.csv` | Lista original de links e pastas de vídeos editados |

## Como usar a planilha

1. Na célula amarela **B4**, digite a data da segunda-feira da semana. As datas de cada dia são preenchidas automaticamente.
2. Na coluna **LINK / LOCAL**, clique no 🔗 para abrir a plataforma. O 📁 indica o nome da pasta ou local, sem link direto.
3. Na coluna **STATUS**, escolha **✔ Concluído** na lista quando terminar a atividade. A linha fica verde e riscada.
4. O topo mostra o percentual da semana e o quadro **Resumo por dia** mostra o andamento de cada dia.
5. Para uma nova semana, troque a data em B4 e volte os status para **☐ Pendente**.

A aba **Central de Links** reúne todos os endereços para consulta rápida.
